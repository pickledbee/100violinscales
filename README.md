# 100 Violin Scales: Positions 1 through 5

An intermediate scale and bowing workbook for violin by Bruce Bowers.

Download the book: [100-Violin-Scales-Positions-1-5.pdf](100-Violin-Scales-Positions-1-5.pdf)

## What is inside (169 pages)

- 100 two-octave and one-string scales in 1st through 5th position, plus shifting scales
- 36 bowing patterns: détaché, legato, staccato, martelé, spiccato, collé, louré, hooked bowing, slurred staccato, and every common slur pattern
- Part 7: a full-page practice edition with every scale on its own page
- Bonus: 28 arpeggios, a bowing guide, a fingerboard map, rhythm variations, a 12-week plan, a scale tracker and a practice log

## Rebuilding the PDF

The `source` folder holds the Python scripts that engrave the notation and lay out the book (ReportLab).
Run `python3 source/book.py 100-Violin-Scales-Positions-1-5.pdf` from inside the `source` folder.
